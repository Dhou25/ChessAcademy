# ♜ Chess Academy Tracker

A lightweight Blazor Web App for tracking chess academy player performance and game records.

## Features
- 📊 Interactive Dashboard with real-time metrics
- 📈 Win/Loss/Draw distribution pie chart (Chart.js)
- ➕ Full CRUD operations for game records
- 🎨 Clean, responsive UI with Bootstrap 5

## Tech Stack
- **Framework:** Blazor Web App (.NET 8)
- **Database:** SQLite + Entity Framework Core
- **Charts:** Chart.js
- **Styling:** Bootstrap 5
